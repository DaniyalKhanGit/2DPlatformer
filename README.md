# 3DGameBoys

A 2D platformer game built in Java from scratch, developed as a team project. Me and one other member handled all programming and engine logic, while the rest of the team created the original art assets and sound.

## About

The game is built without a game engine — all rendering, physics, collision, and game loop logic is written directly in Java. Art assets and audio were created specifically for the project and live in the `res` directory.

## Project Structure

```
src/    game source code (logic, rendering, physics, entities)
res/    art assets and sound files
bin/    compiled output
```

## Running It

Open the project in an IDE (Eclipse recommended — a `.classpath` and `.project` file are included) and run through the main class file.
